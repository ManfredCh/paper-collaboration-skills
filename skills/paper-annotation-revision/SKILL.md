# Paper Annotation Revision

Revise the passage in the manuscript's language. Use the requested review language for annotations and explanations, with the main language of the request as the default. Include a separate translation when the author or project calls for bilingual review.

1. Locate the passage in the active manuscript using the page, section, selected text, and surrounding sentences. Use the author's comment as the instruction and the page or screenshot as location evidence.
2. Track each annotation through its outcome. If several comments point to the same passage, revise it once and map each comment to the change. Handle clear edits while working through any ambiguity that affects the claim.
3. Show the relevant original passage, revised passage, brief rationale, and sources where needed. Include the corresponding translation when requested. Use [Paper Source Trace](../paper-source-trace/SKILL.md) if the edit depends on a disputed fact.
4. Match the author's requested stage. A request to preview revisions calls for a comparison. An approved edit or a direct instruction to update the text calls for a scoped edit to the active manuscript. Update the affected translations, labels, figure captions, and appendix references using [Paper Writing and Review](../paper-bilingual-workflow/SKILL.md).

Use the [fixed offline comparison page](references/review-page.md) for browser review. Highlight the changed original text in yellow and the replacement text in red. Preserve stable anchors and label each item's status. In the clean manuscript, keep the approved text and formal citations.
