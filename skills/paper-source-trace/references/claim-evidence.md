# Claim and Evidence Records

| Manuscript item | Evidence role | Location and conditions | Disposition |
| --- | --- | --- | --- |
| Motivation for a mechanism | Background or writing precedent | Identify the source section, what prompts its argument, and what the following discussion establishes. | Cite relevant background or use the rhetorical structure. |
| Definition of the project's method | Implementation or author handoff | Identify the active entry point and the operations and inputs it uses. | Write or revise the definition within its scope. |
| Reported measurement | Run record or published result | Record the version, unit, denominator, split, protocol, and exact source location. | Report the value, narrow the claim, or request evidence for a material gap. |

For a cross-paper comparison, check whether similarly named fields use different units. For a calculated value, record the formula and inputs. Keep a calculated configuration linked to its calculation, and link an executed configuration to a matching run record. If sources conflict, identify the versions and state which manuscript claim depends on the resolution.
