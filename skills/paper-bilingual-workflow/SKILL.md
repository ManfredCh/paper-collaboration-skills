# Bilingual Paper Workflow

Identify the active manuscript, its build entry point, and the sections or appendices in scope. Use English LaTeX as the manuscript source and the author's requested review language in HTML when adopting this workflow. Follow the project's established source format and the author's language preference.

| Author request | Deliverable |
| --- | --- |
| Outline the paper or describe what each paragraph should do | Map each paragraph to a question, the evidence it will use, and its connection to the next paragraph. |
| Review one paragraph at a time or show the text first | Present the current English passage, the corresponding translation, and relevant sources. Merge changes within the scope the author approves. |
| Polish or make light edits | Preserve the author's structure, terminology, and claims. Fix specific problems in syntax, transitions, or meaning. |
| Apply the revisions or merge the approved draft | Update the active source, review copy, manuscript entry points, and affected figure, table, and appendix references. |

Draft each paragraph in idiomatic English around its scientific purpose, then translate the same claim. In method sections, connect the motivation to the mechanism and its direct consequence. Use the main figure for steps that are easy to see and use the text to define inputs, conditions, and less visible details. Introduce specialized symbols where readers first need them.

Group related work by problem or mechanism. Use [Paper Literature Search](../paper-literature-search/SKILL.md) to find papers, [Paper Source Trace](../paper-source-trace/SKILL.md) to verify a claim or quote, and [Paper Annotation Revision](../paper-annotation-revision/SKILL.md) for marked revisions.

For new review pages, use the [fixed HTML layouts](references/html-pages.md). When editing an existing review copy, keep its layout and anchors. Follow [manuscript synchronization](references/manuscript-sync.md) to check the affected source, translations, citations, and actual build. Provide the working review link and manuscript location.
