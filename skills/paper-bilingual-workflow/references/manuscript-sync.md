# Manuscript Synchronization

- Locate the sections, figures, appendix files, and bibliography used by the actual manuscript build. Check any standalone chapter previews that the author uses.
- Identify the manuscript revision represented by the review copy. Read the current files before editing, especially when another collaborator can change the same chapter. Keep historical comparisons associated with their original revisions.
- Match sections, equations, figures, tables, and references by stable anchors, labels, and citation keys. Regenerate displayed numbers after building the complete manuscript.
- Compare the two languages for mechanism, terminology, claim strength, conditions, and numeric values. Check units, denominators, protocols, and sample counts. Tie each reported result to its corresponding run or analysis.
- Build the requested LaTeX entry point. Inspect unresolved citations, references, and layout problems in the changed sections. When a particular template or page limit matters, check that build directly.
- Open the HTML through the same entry point the author will use. Check that anchors, reference links, and the current revision are visible. Preserve clean manuscript text after merging approved edits.
